## Selected engineering work

### TBOX Modem Diagnostics GUI

*A Python desktop utility for remote diagnostics of an automotive telematics box.*

- Connects to a target device over SSH and runs diagnostic commands remotely.
- Interprets modem responses and presents operator, registration, signal, APN, eSIM profile, and IP-interface information in a readable form.
- Checks relevant system services and helps narrow down common connectivity issues.
- Supports background monitoring, timestamped output, and log export for further investigation.
- Includes guarded, confirmation-based recovery actions for selected modem states.

**Built with:** `Python` · `Tkinter/ttk` · `SSH` · `Linux` · `AT commands` · `JSON` · `threading`
